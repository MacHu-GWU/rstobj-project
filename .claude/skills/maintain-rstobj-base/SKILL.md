rstobj turns Python dataclasses into reStructuredText. Every object is a `RstObj` (`rstobj/base.py`) that renders one jinja2 template from `rstobj/templates/`, chosen by its module and class name. Markup (headers, lists, links) lives in `rstobj/markup/`, directives (`code-block`, `image`, `list-table`, `contents`, `include`) in `rstobj/directives/`; users import both through `rstobj/api.py`. One list of rendering cases (`rstobj/tests/cases.py`) drives both the snapshot tests and the "Rendering Gallery" docs page.

For template conventions (layout, code style, test layout, docs, release), load `pywf-oss-base`. This family holds only what is specific to rstobj.
